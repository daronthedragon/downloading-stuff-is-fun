youtube doesn't allow this from a server
google requires a signed-in account for downloads coming from datacenters, so this site can't fetch youtube links. the whole thing is open source — run it on your own machine and youtube works normally, using your own connection.
get it on github
how to use this
  1. paste a link — any page with a video or track on it.
  2. pick a mode — auto gives video + audio, audio gives a tagged mp3 with cover art, mute gives video with no sound.
  3. hit download — you'll see live progress, then the file saves to your device.

open settings for quality, file format, subtitles, and whole playlists or albums (those arrive as a zip). your choices are remembered on this device.

works here: soundcloud, vimeo, reddit, x, twitch, bandcamp, direct links, and ~1800 more. youtube doesn't: it blocks downloads coming from servers, so run it yourself from github — on your own machine youtube works normally.

everything is virus scanned. every file is checked with clamav before it reaches you — anything infected is deleted and never served.

a track won't download? it's usually paid or private — those are encrypted at the source and can't be fetched. most other things just work.

no ads · no signup · nothing stored — files are deleted the moment you download them
